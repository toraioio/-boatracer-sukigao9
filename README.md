# ボートレーサー好き顔9選

BOAT RACE公式の現役レーサー検索を更新元にする、2択式の好き顔メーカーです。

## GitHub Pages 公開
1. このフォルダの中身をGitHubリポジトリのルートへアップロード。
2. Settings → Pages → Deploy from a branch → main / root を選択。
3. 数分後 `https://toraioio.github.io/リポジトリ名/` で公開。

## 注意
写真はBOAT RACE公式サイトから取得した画像URLを直接表示します。公式サイトの利用条件・著作権等を確認した上で公開してください。
